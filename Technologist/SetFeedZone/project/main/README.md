# ExtensionUtilityNotify usage example

This example demonstrates how to create an extension that will change feed zones of 5D curves.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Install the extension on the CAM start page: open **Extensions**, switch to **Manage** at the top, click **Install from file** on the right and select the file **bin/Debug/SetFeedZone.settings.json**.
3. Restart ENCY.
4. In the utilities list (the **Utilities** button on the top panel or **Ctrl+Shift+E**), select the "**Utility to change feed zones of 5D curves**" item. The feed zones will be changed for selected 5D curves.
