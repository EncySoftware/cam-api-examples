# Machining tools import API usage example

This example of console application for creating a cutting tool.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Start ENCY.
3. Run this project with **./MachiningToolsCreateExampleNet/dotnet run** command.
4. A file **"TestStorage.db"** will appear in the path **./bin/TestStorage.db** that will contain 3 different types of tools.
4. To load and use these tools, in the **Machining** tab you need to open the **Operation parameters** setting window or the **Tool** window, click the **Open Library** button and select the **TestStorage.db** file.


For more information about ENCY cutting tools, visit:
- [Machining tool features](https://docs.encycam.com/ENCY/2/en/10332.html)
