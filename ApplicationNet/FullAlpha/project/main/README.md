# ApplicationNetFullAlpha usage example

This example demonstrates how to create an application that will cwill create a full project (alpha), including file import, operation creation, simulation, and CNC generation in the CAM system.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Start ENCY.
3. Run this project with **./ApplicationNetFullAlpha/dotnet run** command.
4. A new project will be created.Click "Run program" to start application.
