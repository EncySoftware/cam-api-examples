#  ApplicationGeometryImporter usage example

This example demonstrates how to create an application that will import geometry files in the CAM system.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Start ENCY.
3. Run this project with **./GeometryImporter/dotnet run** command.
4. A window for importing geometry files will appear. Click "Open File" and select the file for import.
