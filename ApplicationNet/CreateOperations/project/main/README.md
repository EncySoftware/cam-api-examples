# ApplicationCreateOperations usage example

This example demonstrates how to create an application that will create any operation in the CAM system.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Start ENCY.
3. Run this project with **./ApplicationCreateOperations/dotnet run** command.
4. A window for creating operations will appear.
