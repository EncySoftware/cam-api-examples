# ExtensionUtilityGeomCustomImport usage example

This example demonstrates how to create an extension that will import custom geometry like curves, meshes and vertexes in the CAM system.

# How to build

1. Compile this project with **"./commands/build.cmd"** or menu **"Terminal/Run build task"** in VSCode.
2. Install the extension on the CAM start page: open **Extensions**, switch to **Manage** at the top, click **Install from file** on the right and select the file **bin/Debug/ExtensionUtilityGeomCustomImportNet.settings.json**.
3. Restart ENCY.
4. In the utilities list (the **Utilities** button on the top panel or **Ctrl+Shift+E**), select the "**Utility to import custom geometry (curves) by C#**" item. Custom geometry (curves) will be imported in the CAM system.
5. In the utilities list, select the "**Utility to import custom geometry (meshes) by C#**" item. Custom geometry (meshes) will be imported in the CAM system.
6. In the utilities list, select the "**Utility to import custom geometry (vertexes) by C#**" item. Custom geometry (vertexes) will be imported in the CAM system.
