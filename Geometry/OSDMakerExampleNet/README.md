# OSDMakerExample usage example

This example demonstrates a console application which converts geometry models into **.OSD** file  in the CAM system.

# How to build

1. Build this project with **"dotnet build** .
2. Run application with **dotnet run** or through **.exe**
3. In the documents folder **CAMAPI Geometry examples** will created, where you can find the converted **.OSD** file.
